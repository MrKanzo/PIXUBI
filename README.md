# PIXUBI LAB

Офлайн Android-гра про цифрових вихованців. Kotlin + Jetpack Compose.

Поточна гілка не містить графічних моделей персонажів. Догляд, потреби, сон, сплячка, розвиток, експедиції, магазин, профіль, колекція, мініігри, звук, сповіщення та механізм оновлення залишаються.

Тестування: `gradle --no-daemon testDebugUnitTest assembleDebug`. APK доступний у GitHub Actions після успішної збірки. Стабільний реліз запускається вручну.
