# PIXUBI 🐣
Офлайн Android-гра про цифрових вихованців з п'ятьма різновидами.
**Kotlin + Jetpack Compose**, без реклами й дозволу INTERNET.

## Як завантажити тестову гру
GitHub Actions → Prepare PIXUBI and build APK → останній успішний запуск → Artifacts → pixubi-debug-apk.
Розпакуй ZIP та встанови `app-debug.apk` на Android.

## Статус
MVP 0.1: вибір виду, статі, регіону, випадковий колір, годування, вода, сон, сплячка, одна мінігра. Вільний рух і розмноження ще попереду.

## PIXUBI v0.5 — вікторини та перевірка оновлень
- Шість категорій вікторин: логіка, природа, космос, цифровий світ, світ Піксубі та культура.

- Кнопка «Перевірити оновлення» в ⚙️ налаштуваннях відкриває список GitHub Actions через зовнішній браузер; в самій грі INTERNET permission немає.
- **Важливо:** тестові APK з GitHub підписуються непостійними debug-ключами, тому це **перевірка**, а не автоматичне оновлення/встановлення. Новий v0.5 debug-пакет має суфікс `.quiz` і встановлюється поряд із попередніми; збереження між пакетами не мігрують.

## PIXUBI v0.6 — автоматизоване оновлення як у OS1N7
- ⚙️ → «Перевірити оновлення» запитує **лише останній GitHub Release**, порівнює номер версії та пропонує оновитися.
- Підтверджене оновлення завантажується через системний DownloadManager, після чого Android показує штатний інсталятор.
- Перевіряється назва APK `PIXUBI-release.apk`, домен github.com, розмір, за наявності SHA-256, ідентифікатор пакета, вища версія та підпис.
- Щоденна перевірка в стабільному випуску не впливає на догляд чи вікторини, без інтернету всі базові функції працюють.
- Фіксований **release package id**: `com.pixubi.game.stable`. Debug v0.6 має суфікс `.preview` і **не оновлюється** через GitHub release.
- Для **реальних** безшовних оновлень потрібен незмінний **release keystore**, який **не можна класти в публічний репозиторій**. Підписи GitHub runner debug-пакетів щоразу інші.
- Якщо ключі налаштовані в GitHub Actions secrets, workflow збирає підписаний release і публікує його у Releases як `PIXUBI-release.apk`.
- Рання тестова лінійка 0.1–0.5 мала окремі package IDs та тимчасові підписи. Перехід на стабільну 0.6 потребуватиме **першого окремого встановлення**, старі збереження не переносяться між пакетами.
- Докладні кроки: [docs/UPDATES_AND_SIGNING.md](docs/UPDATES_AND_SIGNING.md).

## PIXUBI v0.7 — життя, ріст, яйця і кокони 🥚
- Нові тваринки народжуються яйцем і проходять п'ять послідовних стадій: яйце → малюк → підліток → кокон → дорослий.
- Візуал: власні піксельні цифрові яйця і світні кокони (кольори й регіональні акценти), різний масштаб малюків і підлітків; дорослі зберігають повну модель із набору 60 спрайтів.
- Ріст вимагає **обох** умов: активного віку та рівня. Яйце відразу, малюк від 15 хв та Lv2, підліток після 1 активного дня й Lv3, кокон після 3 днів і Lv5, дорослий після 4 днів і Lv6.
- XP: їжа +3, вода +2, сон +4, пробудження +1, мінігра +12, прожитий активний день +8. Максимум 50 XP/добу за дії — захист від нескінченного натискання.
- XP, рівень, дні догляду, серія днів і стадії зберігаються в локальній пам'яті. Сплячка не збільшує активний вік. Відновлення зі сплячки зберігає серію.
- Екран: картка росту з XP-прогресом, термінами наступної стадії, кнопкою **«Етапи»** та оглядом усіх форм без перемикання реального віку.
- Старі JSON-збереження (до v0.7), якщо реально відкриті тим самим пакетом, позначаються legacyAdult, не втрачають дорослий вигляд.
- Усі мініігри, звуки та налаштування збережено.
- Test APK v0.7 має окремий пакет `com.pixubi.game.stable.growth` і **не замінює** попередні debug-версії через різні підписи. Release-підпис, за рішенням власника, поки не налаштовано.

## PIXUBI v0.8 — Таємниці еволюції, профіль і колекція 🧬
- Намальовано 10 **нових** персонажів (5 окремих немовлят + 5 серйозніших підлітків із бронею, деталями й іншою поставою). Вони НЕ є збільшеним/зменшеним дорослим спрайтом. Фінальна форма використовує індивідуальні 60 дорослих спрайтів із v0.4.
- Яйце й кокон залишаються окремими процедурами рендерингу та забарвлюються відповідно до генів.
- Жодних майбутніх спойлерів: в галереї «Етапи» яйце та малюк — видимі; ще не вирощені підліток, кокон і доросла форма відображаються **«🔒 ???»**, без малюнка та імені.
- Екран вибору яйця також показує ТІЛЬКИ малюка, а не дорослу модель.
- 👤 Профіль: ім'я, шість аватарів, дата початку гри, рівень гравця, сумарні дні та XP, статистика вирощених, дорослих, вікторин, мініігор і серій догляду.
- 📖 Колекція: 5 видів, 2 статі, 6 забарвлень, 5 стадій = 300 відкриттів; невідомі — затінені секрети.
- Постійна локальна історія кожного вирощеного Піксу, відкрита стадія, виграні мініігри, XP і вік. Профіль не стирається при початку нового життя або смерті попереднього звірятка.
- Перевірки ідентичних відкриттів, граничних рівнів та приховування майбутніх форм виконуються JUnit-тестами.
- Debug тестове ім'я пакета `.mystery` із **окремим** локальним збереженням. Поки без постійного release-підпису, як вирішив власник.
- Система розгалужених навичок, полювання, багатьох фінальних форм та спадковості — наступні версії; не заявляти, що вони вже працюють.

## PIXUBI v0.9 — монетки, запаси, предмети й життя офлайн 🏡🪙
- Хлопчики й дівчатка мають відмінні риси мордочок і кольорові акценти на всіх живих стадіях (не тільки бантик). Початкові 60 генетичних забарвлень залишаються.
- Локальні ресурси: 4 порції їжі, 4 порції води, 2 елементи заряду. Кожна дія витрачає відповідний ресурс. Коли він закінчиться, ресурс треба знайти або придбати.
- Стартовий гаманець: 30 монеток. Мініігри дають по 6 монет за виграш (максимум 30 на день).
- Дослідження світу: Пікс після вилуплення може вирушити на 20-хвилинну експедицію, витрачає 8 енергії, приносить 8 монет і 1 ресурс. До 4 експедицій на місцевий день. Прогулянка завершується за часом навіть коли застосунок був закритий; при ручній сплячці її скасовано.
- В офлайн-крамничці можна купити їжу, воду, зарядні елементи, будиночок, тарілочку, стаканчик та зарядну станцію. Нові предмети з'являються в регіональній сцені.
- Будиночок прискорює відновлення енергії під час сну. Тарілочка й стаканчик покращують відновлення ситості та спраги. Станція підвищує ефективність зарядного елемента.
- При закритті застосунку час відтворюється без фонового сервісу (на підставі часової позначки при наступному запуску), але не більше 12 годин за одну відсутність — щоб пет не загинув через довге відключення телефону. Прогрес додає +1 XP за кожну активну годину плюс добовий бонус. Явна сплячка продовжує повністю зупиняти потреби, старіння та XP.
- Формат збереження підвищено до v3 зі значеннями за замовчуванням для старих вихованців (за умови того самого package ID та сумісного підпису).
- Версія застосунку: `versionCode=9`, `versionName=0.9.0`. Стабільний package ID незмінний: `com.pixubi.game.stable`. Наявні тестові debug APK з різними підписами можуть не встановитися поверх старих: для послідовних оновлень використовувати release APK з одним постійним ключем.
- Тести економіки: `app/src/test/java/com/pixubi/game/PixubiEconomyTest.kt`. Складання/тести слід перевірити в GitHub Actions перед встановленням.

## PIXUBI v0.10 — повідомлення від самого Піксубі 🔔
- Необов'язкові локальні Android-сповіщення про спрагу, голод, втому та сум. Повідомлення пишуться від імені вихованця, зі зверненням за ім'ям і коректним родом у заголовках.
- У налаштуваннях є загальний перемикач (за замовчуванням вимкнено), окремі перемикачі чотирьох категорій, тихі години 22:00–08:00 та кнопка тестового повідомлення.
- Android 13+ запитує `POST_NOTIFICATIONS` лише після згоди власника. Android 8+ має окремий канал «Потреби Піксубі» та піктограму лапки.
- WorkManager робить приблизні перевірки через 30 хвилин, навіть коли гру закрито, без постійного фонового сервісу, без мережі й зайвих дозволів. ОС може затримати їх через обмеження акумулятора.
- Практичний захист від спаму: не частіше 1 повідомлення на 4 години і повтору тієї самої теми на 12 годин; під час гри та одразу після виходу сповіщення не надокучають.
- Сплячка й смерть повністю блокують нагадування; звичайний сон не надсилає пропозицію гратись чи спати.
- Повідомлення не змінюють збереження вихованця у фоні: перевіряють прогноз потреб на базі офлайн-часу; при відкритті використовується попередня механіка безпечного відновлення до 12 годин.
- Підписана лінійка продовжується: `versionCode=10`, `versionName=0.10.0`, `applicationId=com.pixubi.game.stable`.
- Регресійні тести в `PixubiNeedsRulesTest.kt`.
