# PIXUBI 🐣
Офлайн Android-гра про цифрових вихованців з п'ятьма різновидами.
**Kotlin + Jetpack Compose**, без реклами й дозволу INTERNET.

## Як завантажити тестову гру
GitHub Actions → Prepare PIXUBI and build APK → останній успішний запуск → Artifacts → pixubi-debug-apk.
Розпакуй ZIP та встанови `app-debug.apk` на Android.

## Статус
MVP 0.1: вибір виду, статі, регіону, випадковий колір, годування, вода, сон, сплячка, одна мінігра. Вільний рух і розмноження ще попереду.


## PIXUBI v0.2 — живий Піксубі
- 5 видів із мімікою, морганням, рухами та тінню.
- Емоції: радість, сум, сон, сплячка, їжа, вода, втома, здивування від дотику.
- Бульбашки потреб і живі реакції, регіональні декорації.
- Debug APK має суфікс пакета `.preview` для паралельного встановлення з v0.1, щоб не втратити старого вихованця.
- Нові емоції не змінюють формат збереження гри.


## PIXUBI 0.3 — Синтезатор та налаштування 🎵
- П'ять авторських електронних фонових тем для всіх регіонів світу.
- Синтезована мелодія у реальному часі та десять коротких цифрових звукових ефектів.
- Екран налаштувань з кнопкою ⚙️, двома окремими перемикачами і двома повзунками гучності.
- Можливість послухати інші мелодії регіонів без зміни місця проживання тваринки.
- Налаштування зберігаються локально та не впливають на збереження Піксубі.
- Фонова музика зупиняється при виході з гри; немає INTERNET permission.
- Debug тестова версія .sound встановлюється поруч із 0.1 і 0.2; це окреме локальне збереження.
- Для перевірки: `gradle --no-daemon testDebugUnitTest assembleDebug`
