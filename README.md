# PIXUBI 🐣
Офлайн Android-гра про цифрових вихованців з п'ятьма різновидами.
**Kotlin + Jetpack Compose**, без реклами й дозволу INTERNET.

## Як завантажити тестову гру
GitHub Actions → Prepare PIXUBI and build APK → останній успішний запуск → Artifacts → pixubi-debug-apk.
Розпакуй ZIP та встанови `app-debug.apk` на Android.

## Статус
MVP 0.1: вибір виду, статі, регіону, випадковий колір, годування, вода, сон, сплячка, одна мінігра. Вільний рух і розмноження ще попереду.

## PIXUBI 0.3 — Синтезатор та налаштування 🎵
- П'ять авторських електронних фонових тем для всіх регіонів світу.
- Синтезована мелодія у реальному часі та десять коротких цифрових звукових ефектів.
- Екран налаштувань з кнопкою ⚙️, двома окремими перемикачами і двома повзунками гучності.
- Можливість послухати інші мелодії регіонів без зміни місця проживання тваринки.
- Налаштування зберігаються локально та не впливають на збереження Піксубі.
- Фонова музика зупиняється при виході з гри; немає INTERNET permission.
- Debug тестова версія .sound встановлюється поруч із 0.1 і 0.2; це окреме локальне збереження.
- Для перевірки: `gradle --no-daemon testDebugUnitTest assembleDebug`

## PIXUBI v0.5 — вікторини та перевірка оновлень
- Шість категорій вікторин: логіка, природа, космос, цифровий світ, світ Піксубі та культура.
- 72 оригінальні офлайн-запитання (12 у кожній категорії), 5 випадкових у раунді, випадковий порядок відповідей.
- Пояснення правильних відповідей, бонус настрою за >=3/5, окремий локальний лічильник результатів.
- Стара мінігра «Лови іскорки» залишається доступною в ігровому центрі.
- Кнопка «Перевірити оновлення» в ⚙️ налаштуваннях відкриває список GitHub Actions через зовнішній браузер; в самій грі INTERNET permission немає.
- **Важливо:** тестові APK з GitHub підписуються непостійними debug-ключами, тому це **перевірка**, а не автоматичне оновлення/встановлення. Новий v0.5 debug-пакет має суфікс `.quiz` і встановлюється поряд із попередніми; збереження між пакетами не мігрують.

## PIXUBI v0.6 — автоматизоване оновлення як у OS1N7
- ⚙️ → «Перевірити оновлення» запитує **лише останній GitHub Release**, порівнює номер версії та пропонує оновитися.
- Підтверджене оновлення завантажується через системний DownloadManager, після чого Android показує штатний інсталятор.
- Перевіряється назва APK `PIXUBI-release.apk`, домен github.com, розмір, за наявності SHA-256, ідентифікатор пакета, вища версія та підпис.
- Щоденна перевірка в стабільному випуску не впливає на догляд чи вікторини, без інтернету всі базові функції працюють.
- Фіксований **release package id**: `com.pixubi.game.stable`. Debug v0.6 має суфікс `.preview` і **не оновлюється** через GitHub release.
- Для **реальних** безшовних оновлень потрібен незмінний **release keystore**, який **не можна класти в публічний репозиторій**. Підписи GitHub runner debug-пакетів щоразу інші.
- Якщо ключі налаштовані в GitHub Actions secrets, workflow збирає підписаний release і публікує його у Releases як `PIXUBI-release.apk`.
- Рання тестова лінійка 0.1–0.5 мала окремі package IDs та тимчасові підписи. Перехід на стабільну 0.6 потребуватиме **першого окремого встановлення**, старі збереження не переносяться між пакетами.
- Докладні кроки: [docs/UPDATES_AND_SIGNING.md](docs/UPDATES_AND_SIGNING.md).

## PIXUBI v0.7 — життя, ріст, яйця і кокони 🥚
- Нові тваринки народжуються яйцем і проходять п'ять послідовних стадій: яйце → малюк → підліток → кокон → дорослий.
- Візуал: власні піксельні цифрові яйця і світні кокони (кольори й регіональні акценти), різний масштаб малюків і підлітків; дорослі зберігають повну модель із набору 60 спрайтів.
- Ріст вимагає **обох** умов: активного віку та рівня. Яйце відразу, малюк від 15 хв та Lv2, підліток після 1 активного дня й Lv3, кокон після 3 днів і Lv5, дорослий після 4 днів і Lv6.
- XP: їжа +3, вода +2, сон +4, пробудження +1, мінігра +12, прожитий активний день +8. Максимум 50 XP/добу за дії — захист від нескінченного натискання.
- XP, рівень, дні догляду, серія днів і стадії зберігаються в локальній пам'яті. Сплячка не збільшує активний вік. Відновлення зі сплячки зберігає серію.
- Екран: картка росту з XP-прогресом, термінами наступної стадії, кнопкою **«Етапи»** та оглядом усіх форм без перемикання реального віку.
- Старі JSON-збереження (до v0.7), якщо реально відкриті тим самим пакетом, позначаються legacyAdult, не втрачають дорослий вигляд.
- Усі мініігри, звуки та налаштування збережено.
- Test APK v0.7 має окремий пакет `com.pixubi.game.stable.growth` і **не замінює** попередні debug-версії через різні підписи. Release-підпис, за рішенням власника, поки не налаштовано.
