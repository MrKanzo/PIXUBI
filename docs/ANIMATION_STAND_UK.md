# Стенд анімацій PIXUBI

Режим розробника → «🎬 Стенд усіх анімацій • запис відео».
Вибрати вид, стать, вік і колір. 20 плиток на одному екрані, без прокручування:
усі 19 дій DevAction та окремий цикл засинання/пробудження (якщо існує).
Один годинник для всіх сцен, пауза, крок 1/16 с, швидкість, напрямок.
Натискання плитки відкриває збільшений перегляд. Автопоказ проходить всі дії по черзі;
експедиція й автономний режим тривають 12 с, інші 5 с. Екран не засинає.
Використовується WorldScene зі звичайними ресурсами, без підміни картинками.
Умовні тестові предмети ввімкнені для перевірки догляду. Невластиві виду дії
позначені кольором; для відсутніх кадрів переходу сну є явний напис.
Усі тестові пети синтетичні, не змінюють збереження або економіку. Перевірка
на телефоні та фактична плавність 20 сцен ще потрібні.
