# Kraplyk baby: land and face frames (0.28.7)

The original baby artwork is retained. This update uses generated pixel-aligned poses, not a new hand-painted sprite sheet. Walking alternates original paws, rest tucks both paws, and quiet gill movement accompanies idle and rest. Native eyes and mouth follow the current emotion; sleep forces closed eyes even in developer preview. The existing dedicated swim frames and water concealment remain unchanged. Young/adult art, game state and release signing are unchanged.

Developer mode: select baby Kraplyk, inspect walk, blink, happy, sad, tired, eat, drink, sleep and search. Check foot joins and facial texture on device.
