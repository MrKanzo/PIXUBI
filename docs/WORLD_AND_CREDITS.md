# PIXUBI — Маленькі створіння. Великі історії.

Офлайн Android-гра про цифрових вихованців: догляд, розвиток, експедиції, мініігри, колекція, ручна сплячка. Без реклами й обов'язкового акаунта. Інтернет потрібен для перевірки оновлень.

## Творці

- **Микола (MrKanzo)** — автор ідеї, керівник проєкту, творчий напрям, тестування.
- **Аліса (ChatGPT)** — ШІ-співавторка концепції, історій, дизайну, графіки й коду.

## Світ

Після Великої Тиші п'ять потоків енергії подарували життя п'яти видам: Лісик (Смарагдовий ліс), Іскрик (Гірські вершини), Краплик (Озерний край), Піщаник (Золоті дюни), Хмарик (Небесні острови). Повні легенди містяться у грі: Налаштування → Про PIXUBI.

Версії: 0.28.1, 0.28.2 тощо — невеликі оновлення; 0.29.0 та наступні — масштабні.
