# 0.32.0 — native older sprites
New ten character drawings in app/src/main/assets/pixubi_older_v032.png: 192px cells, adults first row, Ultra second row, five species in enum order. All face right. Their face coordinates and appendage polygons are specific to this new artwork, not reused from the low-resolution portraits. Existing baby and juvenile artwork stays intact. Old 48px artwork is not used by the current renderer. Adult/Ultra expressions and motion are derived pixel frames, not independently illustrated motion sheets. Female and genetic variants still use the existing derived appearance system. Device visual review, dedicated sleeping poses, and independent female pose sheets remain open.
