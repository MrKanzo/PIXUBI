# Unified sprite library (0.31.0)

All game views use FramePetSprite → PixuFrameLibrary. The cache stores at most 16 MiB of finished 192×192 cells. Rendering is nearest-neighbor. The original authored baby packs and juvenile Lisyk remain preferred. The other four juvenile forms use their separate illustrated atlas and native face/motion frames. Adult and Ultra forms use their separate reference-derived artwork and per-species discrete pixel motion regions.

The 40 identity combinations have a sex silhouette variant and six genetic accent options. These are derived variants, not forty independently hand-drawn sprite sheets. Adult/Ultra source art remains 48×48; enlarging the cell does not create detail. A sleeping side portrait is not yet a separately drawn lying pose. Device visual review remains necessary, especially eyes, appendage seams and directional movement.

The game engine, save format, signing key and application ID are unchanged. Only obsolete onboarding wording and the rendering route are updated.
