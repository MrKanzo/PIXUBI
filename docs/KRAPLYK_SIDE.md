# Kraplyk side walk (0.28.8)

Baby Kraplyk now uses a separate right-facing pixel illustration with a horizontal axolotl body, four independently posed legs, fin tail, external gills, forehead diamond and profile eyes. Four gait frames are rasterized at 96 logical pixels into 192px bitmaps without antialiasing and cached. Left-facing walk mirrors the dedicated side frame. Ground height remains fixed while walking; the feet provide the gait.

All existing front-facing expressions, sleep and dedicated swimming/water concealment are preserved. Developer mode: baby Kraplyk, Walk, switch direction, then Auto/Idle. The artwork is hand-coded and is not a generated or imported PNG atlas.
